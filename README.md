# 🍺 Kudkara Meetup (ಕುಡುಕರ ಮೀಟ್ ಅಪ್) - Karnataka Local Bar & MRP Edition

A web application designed for liquor shops, MRP outlets (CL-2 / CL-9), and bar management in **Karnataka / Bengaluru**. It features authentic **Karnataka local bar & MRP brands**, volume selection (Peg, Quarter/Nip, Half/Pint, Full/Khamba, Beer Bottles), spicy bar touchings/side dishes, use & throw disposable glasses (₹5–10), chilled mixers, live GPS location delivery checkout, printable tax invoice generation, and WhatsApp order forwarding.
